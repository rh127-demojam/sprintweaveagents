## Overview

CPAT generates every RHOSO deployment Custom Resource via 15 CIQ-driven
Jinja2 templates. Templates are rendered during the **Generate Manifests for
Review** task and written to `artifacts/<cluster>/`. No `oc apply` occurs
until the engineer runs Deploy tasks.

**Total templates: 15** — 8 always generated, 3 conditional (unprovisioned),
4 conditional (disconnected).

Additionally, **1 Ansible task** (`generate_ceph_secret.yml`) generates the
`ceph-conf-files` Secret manifest when `Ceph External = yes`.

#### Ceph Integration (v1.3)

When `Ceph External = yes`, the control plane template configures:
- **Glance**: RBD backend via `customServiceConfig`, `extraMounts` mounting `ceph-conf-files` Secret, `storage.external: true`
- **Cinder**: RBD volume backend with pool, user, FSID, `extraMounts` for CinderVolume + CinderBackup
- **Nova**: `novaComputeTemplates` with `images_type=rbd`, `images_rbd_pool`, `rbd_user`, `rbd_secret_uuid`, `extraMounts` for Nova
- **Swift**: `enabled: true` with `cephConfigMap: ceph-conf-files` when `Ceph RGW Enabled = yes`

## Jinja2 Safety Patterns

All templates follow the boolean coercion fix:

```jinja2
{% if (rhoso_var | default('') | string) | length > 0 %}
```

Multi-document templates use the per-item loop:

```jinja2
{% for item in collection %}---
... CR YAML ...
{% endfor %}
```

Ceph `extraMounts` pattern (used in Glance, Cinder, Nova, NodeSet):

```jinja2
{% if rhoso_ceph_external | bool %}
      extraMounts:
        - name: ceph-conf
          region: default
          extraVol:
            - propagation:
                - <ServiceName>
              extraVolType: Ceph
              volumes:
                - name: ceph
                  secret:
                    secretName: ceph-conf-files
              mounts:
                - name: ceph
                  mountPath: /etc/ceph
                  readOnly: true
{% endif %}
```
